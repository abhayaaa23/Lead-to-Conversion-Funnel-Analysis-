# Lead-to-Conversion-Funnel-Analysis-

An Excel-based business performance dashboard designed to monitor loan disbursement performance, client conversion, and cluster-wise business efficiency in a Joint Liability Group (JLG) lending business.

The dashboard consolidates key performance indicators into a single report to help management monitor business progress, identify conversion gaps, and compare cluster performance.

## 📊 Project Overview

This project focuses on analysing the client journey from login to credit bureau pass and eventual loan disbursement.

The dashboard provides a consolidated view of business performance through KPI cards, a conversion funnel, cluster-wise comparisons, and business highlights.

**Objective:** To simplify daily business monitoring and help management identify areas requiring further investigation.

## 🎯 Business Problems Addressed

* How many clients have been logged in during the month?
* How many clients have passed the credit bureau stage?
* How many clients have been successfully disbursed?
* What is the Login-to-Disbursement conversion rate?
* Which clusters are performing better?
* How many clients are between the login and disbursement stages?
* Which clusters may require further performance analysis?

## 📈 Key Performance Indicators

The dashboard tracks the following metrics:

| KPI                              | Description                                                        |
| -------------------------------- | ------------------------------------------------------------------ |
| Total Login MTD                  | Total clients logged in month-to-date                              |
| CB Pass                          | Number of clients who passed the credit bureau stage               |
| CB Pass Rate                     | Percentage of logged-in clients who passed the credit bureau stage |
| Disbursed MTD                    | Number of clients disbursed month-to-date                          |
| Login-to-Disbursement Conversion | Percentage of logged-in clients who reached disbursement           |
| Client Gap                       | Difference between logged-in clients and disbursed clients         |
| Disbursed Amount MTD             | Total disbursement amount month-to-date                            |

*MTD stands for Month-to-Date.*

## 📉 Dashboard Components

### 1. KPI Summary

Provides a quick overview of the key business metrics so that management can understand overall performance at a glance.

### 2. Login-to-Disbursement Funnel

Visualises the client journey through three stages:

**Login → CB Pass → Disbursed**

This helps identify the numerical gaps between consecutive stages.

### 3. Cluster-wise Conversion Analysis

Compares Login-to-Disbursement conversion across the following clusters:

* Hisar
* Rewari
* Jhunjhunu

This makes it easier to identify differences in conversion performance between clusters.

### 4. Cluster Performance Table

Displays cluster-wise login volume, CB Pass count, disbursed clients, client gap, and total conversion.

### 5. Business Highlights

Summarises key observations that may require management attention.

## 🔍 Key Insights from the Sample Report

The following observations are based on the sample dashboard.

| Metric                           |        Value |
| -------------------------------- | -----------: |
| Total Login MTD                  |  567 clients |
| CB Pass                          |  404 clients |
| Disbursed MTD                    |  289 clients |
| Login-to-Disbursement Conversion |       50.97% |
| Login-to-CB Pass Conversion      |       71.25% |
| Login-to-Disbursement Client Gap |  278 clients |
| Disbursed Amount MTD             | ₹1,75,90,000 |

### Cluster-wise Conversion

| Cluster   |   Login | CB Pass | Disbursed | Conversion |
| --------- | ------: | ------: | --------: | ---------: |
| Hisar     |     272 |     181 |       121 |        44% |
| Rewari    |     197 |     158 |       126 |        64% |
| Jhunjhunu |      98 |      65 |        42 |        43% |
| **Total** | **567** | **404** |   **289** |    **51%** |

### Key Observations

* Rewari has the highest Login-to-Disbursement conversion among the three clusters.
* Hisar and Jhunjhunu have lower conversion rates than Rewari and may require further investigation.
* The difference between total login clients and disbursed clients is 278.
* Further analysis of stage-wise drop-offs could help identify opportunities to improve conversion.

*These observations describe the sample report and do not establish the causes of differences in performance.*
